Virtual Pet — виртуальный питомец
Описание проекта
Virtual Pet — небольшая текстовая игра на Python 3. Пользователь ухаживает за виртуальным питомцем: кормит его, играет с ним, укладывает спать и следит за его состоянием.

В игре отображаются основные характеристики питомца:
- Голод - насколько питомец хочет есть. 
- Энергия - насколько питомец бодр.
- Счастье - насколько питомец доволен.
- Настроение - текстовая оценка состояния питомца.
- Игровые ходы - количество выполненных действий.
Также предусмотрено сохранение состояния питомца в файл save.json и загрузка сохранённой игры при следующем запуске.
Возможности
1. Создание питомца с выбранным именем.
2. Кормление питомца.
3. Игра с питомцем с учётом уровня энергии.
4. Сон для восстановления энергии.
5. Просмотр характеристик и настроения.
6. Сохранение и загрузка состояния игры.
7. Проверка некорректного выбора в меню.
Требования
- Python 3.
- Сторонние библиотеки не требуются: используются модули стандартной библиотеки Python.
Структура проекта
VirtualPet/
├── main.py          # Основная программа
├── test_main.py     # Автоматические тесты
├── README.md        # Описание проекта и инструкция
└── save.json        # Файл сохранения, создаётся во время игры
Папка .venv, если она создана PyCharm, нужна только для локального виртуального окружения и не является исходным кодом проекта.
Как запустить игру
1. Откройте папку проекта в PyCharm.
2. Убедитесь, что для проекта выбран интерпретатор Python 3.
3. Откройте main.py.
4. Нажмите правой кнопкой мыши в редакторе и выберите Run 'main'.
5. Следуйте инструкциям в консоли.
Также игру можно запустить из терминала командой:
python main.py
В Windows при необходимости используйте:
py main.py
Как запустить автоматические тесты
Откройте test_main.py в PyCharm и выберите Run 'test_main'.

Либо выполните в терминале:
python -m unittest -v test_main.py
В Windows при необходимости:
py -m unittest -v test_main.py
Тесты проверяют основные функции и граничные случаи программы. Успешное выполнение завершается сообщением OK.
Сценарии проверки
Сценарий 1. Обычный игровой процесс
1. Запустить main.py и создать питомца, введя его имя.
2. Выбрать кормление.
3. Выбрать игру, если энергии достаточно.
4. Уложить питомца спать.
5. Открыть просмотр состояния.
Ожидаемый результат: программа выполняет выбранные действия, изменяет характеристики питомца в соответствии с действиями и показывает актуальное состояние.
Сценарий 2. Сохранение и загрузка
1. Запустить игру и создать питомца.
2. Изменить его характеристики несколькими действиями.
3. Выбрать пункт меню «Сохранить игру».
4. Завершить программу.
5. Запустить игру снова и выбрать загрузку сохранённого питомца, если программа предлагает такую возможность.
6. Просмотреть состояние питомца.
Ожидаемый результат: загружается ранее сохранённый питомец с сохранёнными характеристиками и игровым прогрессом.
